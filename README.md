# 🍯 HoneyChain

### Blockchain-Based Honey Traceability & Smart Beekeeping Management

HoneyChain is a web-based platform designed to improve honey traceability
and support beekeeping management through digital technology.

## 🌐 Live Demo

👉 https://honeychain-ebon.vercel.app

## ✨ Key Features

- User registration and login
- Role-based dashboards
- Hive registration and management
- Hive inspection records
- Digital honey traceability concept

## 🛠️ Tech Stack

- Frontend: React, Vite
- Backend: FastAPI
- Database: SQLite
- Deployment: Vercel

## 📂 Project Structure

- `frontend/` – React web application
- `backend/` – FastAPI backend

## 🚀 Project

HoneyChain aims to bring transparency to the honey
supply chain while helping beekeepers manage hive data.
